# Extension Icons

This folder should contain the following icon files for the browser extension:

- `icon16.png` - 16x16 pixels (browser toolbar)
- `icon48.png` - 48x48 pixels (extension management page)
- `icon128.png` - 128x128 pixels (Chrome Web Store)

## Creating Icons

You can create these icons using any image editor. Recommended tools:

- [Figma](https://www.figma.com/) - Free online design tool
- [GIMP](https://www.gimp.org/) - Free desktop image editor
- [Canva](https://www.canva.com/) - Easy online design tool

## Icon Design Tips

1. Use a simple, recognizable symbol (e.g., a book, Kindle device, or letter 'K')
2. Use high contrast colors for visibility
3. Keep the design simple - it needs to be clear at 16x16 pixels
4. Consider using your brand colors (e.g., purple gradient from the website)

## Quick Icon Generation

For a quick start, you can:

1. Go to https://www.favicon-generator.org/
2. Upload any image or logo
3. Select the sizes: 16x16, 48x48, 128x128
4. Download and place them in this folder
5. Rename them to match the names above

## Placeholder Icons

Until you create proper icons, the extension will use the default Chrome extension icon.
